# 非遗跨境展演知识边界

本项目用于整理非遗跨境展演知识边界领域中的事件名称、交换字段与脱敏样例，方便业务、运营和研发人员在同一套术语下讨论后续服务。资料只包含领域约定，不包含真实个人信息、生产连接或外部账号。

## 目录

- `src/heritage_exchange_boundary.js`：事件种类、最小字段校验与敏感等级词表。
- `src/knowledge_license_service.js`：知识许可包领域服务（内存实现，事件溯源）。
- `data/sample.json`、`data/sample_package_issued.json`：用于核对资料格式的虚构事件。
- `tests/`：保证样例与领域约定保持一致，并覆盖许可包服务的关键行为。

## 知识许可包服务

围绕事件资料维护来源、译文、许可包、用途申报与处置，核心约定：

- **来源**：登记贡献者、敏感等级（`public`/`internal`/`restricted`/`sealed`）与可用地域；权利条件变化与贡献者撤回写入权利时间线。
- **译文**：按语言与版本演进，审校记录审校人与审校意见；纠正版本经审校通过后取代旧版（`corrects` 链）。
- **发行**：`issuePackage` 固定本次采用的来源、译文、用途、接收机构与失效条件；`package_id` 一经发行即绑定 `project_id`，同一许可不可移到另一个项目；送达按机构各自推进，单一机构失败不影响其余机构。
- **用途申报**：接收方提交的实际用途按其**发生时刻**对照当时有效的授权与限制判定，不得超过包内授权；越界或过期用途直接进入处置。
- **三类变更只作用于尚未发生的使用**：权利条件变化、贡献者撤回、翻译更正均不追溯既往，过去合规的履约仍可审计。
- **回执**：可离线乱序到达，每个机构的确认版本只增不减，旧确认不会覆盖新限制。
- **恢复**：`snapshot()` 同时持久化事件日志与通知出站队列；恢复后 `runMaintenance(now)` 补做到期停用与待确认提醒，通知按幂等键去重，不会重复发送。
- **反查**：`explainUse(use_id)` 从一项用途回到当时使用的译文版本、审校人、批准人与批准范围，以及后续限制及其原因。
